# ORS 701.547 Model list of accessibility features; rules.
The Construction Contractors Board shall adopt by rule a model list of features recommended for inclusion in a list of features that a developer supplies to a purchaser of residential housing under ORS 701.545. In developing the model list of features, the board shall solicit the comments of advocacy groups and other organizations serving persons with disabilities. [Formerly 701.530]
