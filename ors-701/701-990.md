# ORS 701.990 Criminal penalties.
(1) Violation of ORS 701.021 is a Class A misdemeanor.
(2) The intentional use of a contractor's license number without the authorization of the licensed contractor is a Class A misdemeanor.
(3) Use of a contractor's license number, with or without the authorization of the licensed contractor, with the intent to deceive the public is a Class A misdemeanor.
