# ORS 343.595 Requirement that textbook publishers supply material in format from which Braille version can be produced.
The State Board of Education shall require a publisher of a textbook adopted by a school district to furnish the Oregon Textbook and Media Center with computer diskettes for literary subjects in a computer-accessible format from which Braille versions of the textbook can be produced. The publisher shall furnish the center with computer diskettes in a computer-accessible format for nonliterary subjects, such as natural sciences, computer science, mathematics and music, when Braille specialty code translation software is available.
