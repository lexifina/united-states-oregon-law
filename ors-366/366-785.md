# ORS 366.785 Definitions for ORS 366.785 to 366.820.
As used in ORS 366.785 to 366.820, unless the context requires otherwise:
(1) "Year" means a calendar year.
(2) "City" means only cities of this state which are regularly operating as such through elected governmental officers.
(3) "Population" means population as given in the latest determination of Portland State University.
