# ORS 30.050 Apportionment among dependents after judgment.
Except when all beneficiaries otherwise agree, if the action described in ORS 30.020 is brought, and a judgment for the plaintiff is given, and there is more than one beneficiary, the amount to be distributed to each beneficiary as recovery for loss described in ORS 30.020 (2)(d) shall be apportioned by the trial court to each beneficiary in accordance with the beneficiary's loss.
