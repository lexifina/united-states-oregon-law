# ORS 527.706 Program of photogrammetric mapping; rules.
(1) As used in this section, "photogrammetric mapping" has the meaning given that term in ORS 672.002.
(2) To aid in monitoring compliance with ORS 527.610 to 527.770 and rules adopted thereunder, the State Board of Forestry shall adopt rules that:
(a) Require persons that file notifications pursuant to ORS 527.670 (6) to inform the State Forester when the operations are complete, within a reasonable time after completion;
(b) Authorize the State Forester to use a program of photogrammetric mapping to determine whether operations for which notifications have been filed pursuant to ORS 527.670 (6) have been completed; or
(c) Otherwise establish a program for determining when operations for which notifications have been filed pursuant to ORS 527.670 (6) have been completed.
(3) Rules described in subsection (2)(b) or (c) of this section must limit the discretion of the person conducting the compliance monitoring.
