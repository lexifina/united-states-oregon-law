# ORS 455.080 Inspector may require proof of compliance.
Notwithstanding ORS 455.630 (2), any inspector, including a specialty code inspector licensed under ORS 455.457, authorized by ORS 455.150 or 455.153 to determine compliance with the requirements of the state building code or any specialty code under this chapter may, in accordance with a compliance program as described in ORS 455.153 (2), require any person who is engaged in any activity regulated by the state building code to demonstrate proof of compliance with the applicable licensing, registration or certification requirements of ORS chapters 446, 447, 455, 460, 479, 480, 693 and 701.
