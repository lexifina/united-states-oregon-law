# ORS 496.375 "Nongame wildlife" defined.
As used in ORS 496.385 and 496.390 "nongame wildlife" means all wildlife species over which the State Fish and Wildlife Commission has jurisdiction, except game mammals, as defined in ORS 496.004, fur-bearing mammals as defined in ORS 496.004, game birds as defined in ORS 496.007 and game fish as defined in ORS 496.009.
