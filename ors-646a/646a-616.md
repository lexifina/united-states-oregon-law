# ORS 646A.616 Effect of request for consumer report subject to security freeze.
If a third party requests access to a consumer report on which a security freeze is in effect, the request is in connection with an application for credit or any other use, the consumer does not allow the consumer's consumer report to be accessed for that period of time, and the third party cannot obtain the consumer report through ORS 646A.614, the third party may treat the application as incomplete.
